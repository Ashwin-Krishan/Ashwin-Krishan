### 🚧 Projects

**[Focalis](https://ashwinkrishan.com/projects/focalis)** · Python, OpenCV, MediaPipe, Rust, Tauri, React, TypeScript, SQLite  
A desktop culling app that checks sharpness where the subject's eyes are, by matching the camera's autofocus data against detected faces. It flags blinks, groups bursts and suggests a keeper from each one.
- A Python scoring engine runs as 3 parallel workers behind a Tauri, Rust and React app.
- It groups a 723-photo shoot into 135 bursts in about 5 seconds.
- Fixing two Sony metadata bugs found in real-shoot testing raised autofocus-to-eye agreement from 19 to 61 of 97 portraits.
- Per-photo scoring time is down 45%, from 673 to 372 ms.
- The engine, `focalis-engine`, will be open-sourced.

**[OpsBridge](https://ashwinkrishan.com/projects/opsbridge)** · React, JavaScript  
A browser-based workflow tool I built as a PM intern to run the national McDonald's drive-thru menu board rollout across 1,100+ Canadian locations. It cut daily ops overhead by 95%, with an instant lookup of every store's cable instructions and lane configurations. It's an internal tool, so there's no public repo.

**[Temple photo gallery](https://photos.vinaayagar.com)** · Next.js, Vercel, Cloudflare R2, GitHub Actions, Google Drive API · [repo](https://github.com/Ashwin-Krishan/svvphotos)  
A community photo gallery for Sri Varasiththi Vinaayagar Hindu Temple of Toronto. Photos dropped into Google Drive sync to Cloudflare R2 on a schedule through GitHub Actions, with nobody touching the site.
